Questions fréquentes

Compte et inscription

Comment créer un compte ? Téléchargez l'application sur l'App Store ou Google Play, puis suivez les étapes d'inscription (email, mot de passe, profil de base, profil psycho-comportemental).

J'ai oublié mon mot de passe. Sur l'écran de connexion, cliquez sur "Mot de passe oublié". Un lien de réinitialisation vous sera envoyé par email (valide 1 heure).

Comment supprimer mon compte ? Réglages → Mon compte → "Supprimer mon compte". La suppression est définitive, vos données seront effacées sous 30 jours conformément au RGPD.

Comment modifier mes informations personnelles ? Réglages → Mon profil → modifier les champs souhaités → enregistrer.

Matching et profils

Comment fonctionne l'algorithme de matching ? SmatchRoom utilise la technologie Ghost Profiling™, un système d'analyse psycho-comportementale qui propose des colocataires compatibles selon le mode de vie, sans questionnaire intrusif. L'algorithme combine vos préférences déclarées et vos interactions in-app pour affiner les suggestions au fil du temps.

Mes données psycho-comportementales sont-elles partagées ? Non. Le profil détaillé reste privé et n'est jamais communiqué à d'autres utilisateurs ou à des tiers. Seules les suggestions de match résultantes vous sont présentées.

Comment signaler un profil inapproprié ? Sur la fiche du profil → bouton "..." → "Signaler". Notre équipe de modération examine sous 24h.

Annonces et propriétaires

Comment publier une annonce de colocation ? Onglet "Publier" → choisir le type d'annonce (recherche colocataire / propose chambre) → remplir le formulaire. Photos requises (jusqu'à 8). Modération automatique, publication immédiate sauf détection de contenu suspect.

Combien coûte la publication d'une annonce ? Gratuit pour les particuliers. Les agences immobilières disposent d'une offre dédiée (49 € HT/mois) avec annonces illimitées : voir SmatchRoom Pro sur pro.smatchroom.com.

Pourquoi mon annonce a-t-elle été retirée ? Les motifs habituels : photos non conformes, prix manifestement faux, description ambiguë, signalement par un utilisateur, contact incomplet. Vous recevez un email d'explication. Vous pouvez contester via support.

Messagerie et communication

Comment envoyer un message à un match ? Lorsqu'un match est confirmé par les deux parties, la messagerie s'ouvre. Cliquez sur la conversation depuis l'onglet "Messages".

Les messages vocaux et appels visio ne fonctionnent pas. Vérifiez que vous avez autorisé l'accès au microphone (et à la caméra pour la visio) dans Réglages → SmatchRoom → Microphone / Caméra. Vérifiez aussi que votre connexion internet est stable.

Comment bloquer un utilisateur ? Dans la conversation ou sur sa fiche profil → bouton "..." → "Bloquer". Aucun nouveau message ne pourra vous être envoyé.

Technique

L'application ne se lance pas ou crash.

  1. Vérifiez que votre OS est à jour (iOS 13+ ou Android 8+)
  2. Forcez la fermeture et relancez
  3. Désinstallez et réinstallez l'app (vos données sont préservées côté serveur)
  4. Si le problème persiste, contactez le support avec le modèle de téléphone + OS

L'application est très lente.

  1. Connexion internet : tester un autre réseau Wi-Fi ou 4G/5G
  2. Libérer de l'espace sur votre téléphone
  3. Mettre à jour vers la dernière version

Comment activer/désactiver les notifications ? Dans l'app : Réglages → Notifications → activer/désactiver par type. Au niveau système : Réglages téléphone → SmatchRoom → Notifications.

Signaler un bug

Pour signaler un dysfonctionnement reproductible, envoyez un email à a.fontana@smatchroom.fr avec :

  • Étapes pour reproduire le bug
  • Comportement attendu vs comportement observé
  • Modèle de téléphone, version OS, version app
  • Captures d'écran ou vidéo si possible

Les bugs critiques (impossibilité d'utiliser l'app) sont traités sous 24h. Les autres sous 5 jours ouvrés.
